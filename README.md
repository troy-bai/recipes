## 🔌 推薦的 Obsidian 插件
為了實現您的**口語化查詢**與**主題篩選**功能，建議您在 Obsidian 中安裝以下社群插件：

1.  **[Smart Connections](https://github.com/brianpetro/obsidian-smart-connections)** (推薦 ⭐⭐⭐⭐⭐)
    *   **用途**：提供 AI 語意檢索。
    *   **效果**：您可以直接用口語提問：「我今天想用里肌肉做菜，有沒有下飯的台式作法？」它會自動讀取您所有食譜，給出具體的菜色建議。
2.  **[Dataview](https://github.com/blacksmithgu/obsidian-dataview)**
    *   **用途**：動態表格與清單查詢。
    *   **效果**：可以用簡單的語法自動列出所有「台式風格」或「包含雞肉」的食譜，不需要手動整理。
3.  **[Omnisearch](https://github.com/scambier/obsidian-omnisearch)**
    *   **用途**：強大的本地全文檢索，支援圖片 OCR。
